SQL Project (20 pts) 
Title: Build a Simple Online Store Database 

 

Objective : 

Design and query a relational database to manage and analyze store data 

 

Skill Focus: 

Table creation and data types  

Primary and foreign keys  

Data insertion (INSERT)  

Querying data (SELECT, WHERE)  

Table relationships (JOIN)  

Data analysis (SUM, GROUP BY)  

 

Tools: 

Students may use: 

BeeKeeper 

SQLite Online  

MySQL Workbench  

 

Project Overview 

Students will build a mini online store database with three main tables: 

Customers  

Products  

Orders  

They will then query the database to extract meaningful insights. 

 

Part 1: Database Structure (5 pts) 

Task: Create the database tables 

Requirements: 

Create 3 tables: Customers, Products, Orders  

Each table must include a primary key  

Orders table must include foreign keys linking to Customers and Products  

Deliverable: 

SQL code showing CREATE TABLE statements  

Rubric (5 pts): 

5 pts: All tables correct with keys and relationships  

3–4 pts: Minor errors in structure  

1–2 pts: Major issues or missing tables  

0 pts: Not attempted
